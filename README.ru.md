# Bitrix24 MCP Server

[🇬🇧 English](README.md) | [🇷🇺 Русская версия](README.ru.md)
![Version](https://img.shields.io/badge/version-1.0.0-blue.svg)
![License](https://img.shields.io/badge/license-MIT-green.svg)

Этот проект представляет собой **MCP (Model Context Protocol) сервер** для интеграции нейросетей (например, Claude от Anthropic) с вашим порталом **Битрикс24**. Сервер позволяет нейросетям напрямую получать данные, управлять CRM, задачами и базами знаний через стандартизированный API.

## Возможности (Tools)

Сервер предоставляет ИИ следующие инструменты:
- **CRM:** Сделки (чтение, списки), Контакты (чтение, списки).
- **Задачи (Tasks):** Чтение задач, списки, создание, обновление, закрытие, добавление комментариев.
- **Scrum:** Просмотр эпиков и привязка задач к эпикам.
- **Базы знаний (Knowledge Base 2.0):** Чтение баз знаний, просмотр структуры, создание, редактирование и получение страниц в формате Markdown.
- **Структура компании:** Получение информации о текущем пользователе, поиск и список сотрудников компании (teammates).

## Требования

- Node.js >= 22 (или Docker)
- Права администратора в вашем портале Битрикс24 (для создания интеграции)
- Anthropic Claude Desktop (или другой клиент с поддержкой MCP)

## Установка и настройка

### Шаг 1. Создание Локального приложения в Битрикс24

Чтобы сервер мог общаться с вашим порталом, вам необходимо создать интеграцию.
1. В левом меню Битрикс24 перейдите в **Приложения** -> **Разработчикам** -> **Другое** -> **Локальное приложение**.
2. Установите галочку "Использует API".
3. **Обязательно добавьте следующие права (скоупы):**
   - `crm` (CRM)
   - `task` (Задачи)
   - `tasks_extended` (Задачи расширенные)
   - `note` (База знаний 2.0)
   - `user` (Пользователи)
4. В качестве **Путь для первоначальной установки** и **URL вебхука** можно указать ваш будущий домен сервера или просто `https://localhost:3000`. 
5. Сохраните приложение и запишите **Код приложения (Client ID)** и **Ключ приложения (Client Secret)**.

### Шаг 2. Настройка сервера

Склонируйте репозиторий и установите зависимости:

```bash
git clone https://github.com/yourusername/bitrix24-mcp-server.git
cd bitrix24-mcp-server
npm install
```

Создайте файл `.env` в корне проекта (или скопируйте `.env.example`) и заполните данные:

```env
PORT=3000
BITRIX24_CLIENT_ID=ваш_код_приложения
BITRIX24_CLIENT_SECRET=ваш_ключ_приложения
BITRIX24_PORTAL_URL=https://ваша-компания.bitrix24.ru
```

### Шаг 3. Запуск

Вы можете запустить сервер двумя путями:

**Вариант А: Через Node.js**
```bash
npm run build
npm start
```
Для фоновой работы на сервере рекомендуем использовать `pm2`:
```bash
pm2 start dist/index.js --name bitrix24-mcp-server
```

**Вариант Б: Через Docker**
```bash
docker-compose up -d
```

Сервер запустится на порту `3000` и будет готов принимать SSE-соединения.

### Шаг 4. Настройка Claude Desktop (клиента)

Если вы запускаете этот сервер удаленно (например, на VPS) и хотите подключить его к своему локальному приложению Claude Desktop, вам нужно будет пробросить порт или настроить Nginx Reverse Proxy. 

В файле настроек Claude (`claude_desktop_config.json` на MacOS: `~/Library/Application Support/Claude/claude_desktop_config.json`) добавьте следующее:

```json
{
  "mcpServers": {
    "bitrix24": {
      "command": "npx",
      "args": [
        "-y",
        "@modelcontextprotocol/inspector",
        "http://адрес-вашего-сервера:3000/sse"
      ]
    }
  }
}
```
*Примечание: в этом примере используется встроенный инспектор, если вы хотите подключаться по HTTP SSE. В случае запуска сервера локально вы можете использовать `command: "node", args: ["/путь/к/bitrix24-mcp-server/dist/index.js"]` (если сервер поддерживает stdio).*
